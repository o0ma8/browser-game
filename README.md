# اندفاع النيون

لعبة أركيد سريعة تعمل مباشرةً في المتصفح، بدون مكتبات أو أدوات بناء.

## طريقة اللعب
- اضغط **ابدأ اللعب**.
- استخدم **مسافة** أو **↑** للقفز فوق الحواجز.
- استخدم **↓** للانخفاض تحت الحواجز.
- على الهاتف، المس الشاشة للقفز أو استخدم الأزرار الظاهرة.
- اجمع البلورات الذهبية لتحصل على نقاط إضافية، وحاول تحطيم أفضل نتيجة المحفوظة على جهازك.

## تشغيل اللعبة محليًا
افتح `index.html` في متصفح حديث.

## النشر عبر GitHub Pages
1. افتح **Settings** في المستودع.
2. اختر **Pages** من القائمة الجانبية.
3. في **Build and deployment**، اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)`، ثم اضغط **Save**.
5. بعد اكتمال النشر، سيظهر رابط اللعبة في صفحة **Pages**. عادةً يكون بالشكل `https://o0ma8.github.io/browser-game/`.
