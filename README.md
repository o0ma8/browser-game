# حديقة الأذكياء 🌈

موقع ألعاب ذهنية عربي للأطفال، يعمل على الحاسوب والهاتف مباشرةً من المتصفح، بدون مكتبات أو تسجيل دخول.

## الألعاب
- **محقق الأنماط:** اختر الصورة التي تكمل سلسلة الأشكال والألوان. يساعد على ملاحظة الأنماط والتفكير المنطقي.
- **حديقة الذاكرة:** شاهد تسلسل الألوان ثم أعده بالترتيب. يدرّب الانتباه والذاكرة العاملة.

لا يوجد مؤقت أو عقوبة على الخطأ؛ يمكن للطفل أن يأخذ وقته ويحاول من جديد. تحفظ اللعبة عدد النجوم خلال الجلسة فقط، ولا ترسل أو تجمع أي معلومات شخصية.

## التشغيل
افتح `index.html` في متصفح حديث، أو انشر المستودع باستخدام GitHub Pages:
1. افتح **Settings → Pages**.
2. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`.
3. اضغط **Save** وانتظر حتى يكتمل النشر.

الموقع منشور عادةً على: https://o0ma8.github.io/browser-game/
